# Introduction au MLOps

Comprendre comment un modèle devient un service utilisable, puis mettre en pratique les premières étapes de son cycle de vie.

## Parcours

1. [Introduction au MLOps](01-introduction.md) : besoin métier, modèle, API et cycle de vie.
2. [Lab Codespaces](02-lab-codespace.md) : créer le dépôt de travail et installer Anaconda.
3. [Lab local](03-lab-docker-local.md) : installer Anaconda et Docker sur son ordinateur.
4. [Jupyter et Parquet](04-run-jupyter-notebook.md) : lancer un notebook et lire les données de trajets.
5. [Prédiction de la durée](05-duration-prediction.md) : préparer les trajets, entraîner trois modèles et comparer leur RMSE.
6. [Mise en pratique](cours.md) : données, entraînement, évaluation et reproduction.

L'introduction s'appuie sur l'estimation d'un trajet en taxi.

Les deux laboratoires permettent de travailler depuis Codespaces ou depuis un environnement Docker local.
